어두운 화면 위에 포스터가 주인공이 되도록 만들었습니다. 이미지를 누르면 크게 볼 수 있습니다.

Features

주요 기능

"보기 편하게"와 "정리하기 편하게", 두 가지에 집중했습니다.

🎞감상

  • 웹 페이지 안의 영상만 화면 전체에 띄우는 전체화면 뷰어
  • 직접 만든 조작부: 진행 바, 10초 이동(버튼·더블탭), 재생 속도, 음량
  • 이어보기: 마지막 위치부터 다시 재생
  • 외부 앱에서만 재생되는 영상은 해당 앱으로 연결

📋목록 관리

  • 시청 상태 자동 판단, 직접 바꾸면 그 값이 우선
  • 별 5개를 끌어서 0.1 단위로 매기는 별점
  • 포스터 보기 / 목록 보기, 썸네일 진행률 막대
  • 공유 메뉴로 추가, 짧은 링크 자동 풀기, 백업 / 복원

🎬영화 정보

  • 제목·원제·연도·감독으로 TMDB에서 찾아 자동으로 연결
  • 장르, 상영시간, 국가, 출연, 평점, 줄거리, 포스터
  • 한국인 감독은 한글 이름, 나머지는 원어 이름으로 통일
  • 감독 페이지에서 필모그래피 확인, 없는 영화는 바로 추가

🔍검색 패널

  • 검색어와 6가지 정렬(오름/내림)
  • 시청 상태, 감독, 장르, 연대, 국가 태그 필터
  • 같은 줄은 "또는", 줄끼리는 "그리고"
  • 앱을 껐다 켜도 필터 상태 유지
